# Stock Price Checker

This is the boilerplate for the Stock Price Checker project. Instructions for building your project can be found at https://freecodecamp.org/learn/information-security/information-security-projects/stock-price-checker
Full-stack JavaScript solution for the freeCodeCamp Information Security Stock Price Checker project.

## Run locally

    npm install
    npm start

Open http://localhost:3000/.

## Run the five functional tests

    npm test

The API supports one or two stock symbols. A single-stock response contains likes; a two-stock response contains rel_likes, the difference between the two like counts. Like identities are stored as salted SHA-256 hashes rather than raw IP addresses.
